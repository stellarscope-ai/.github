## What We Build

**StellarScope AI** is an open-source blockchain intelligence platform that uses AI to help anyone explore Stellar network activity — with verified data and source links for every claim.

| Project | Description | Status |
|---------|-------------|--------|
| [stellarscope-ai](https://github.com/stellarscope-ai/stellarscope-ai) | Main web application | v0.1 Beta |

## Our Principles

- **Verified data over guesses** — Every AI answer links to on-chain source transactions
- **Open source by default** — MIT licensed, community-driven development
- **Blockchain-native** — Soroban smart contracts, Stellar Horizon integration
- **Developer-first** — TypeScript monorepo, clean APIs, comprehensive docs

## Revenue Model

StellarScope AI uses on-chain subscriptions powered by Soroban smart contracts:

| Tier | Price | Features |
|------|-------|----------|
| **Free** | 0 XLM | Basic lookups, 5 watchlist items |
| **Basic** | 1 XLM/month | Full analytics, email alerts |
| **Premium** | 5 XLM/month | Unlimited, priority API, advanced analytics |

Payments go directly on-chain — no intermediaries.
